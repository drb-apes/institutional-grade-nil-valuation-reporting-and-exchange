# Institutional Grade NIL Valuation & Exchange

This project is a TypeScript monorepo for a dual-track NIL valuation and exchange platform.

## Workspaces
- `apps/api` — Express API service
- `apps/web` — React + Vite frontend
- `packages/shared` — shared risk and valuation logic

## Quick start

```bash
npm install
npm run dev:api
npm run dev:web
```

The API runs on `http://localhost:4000` and the web app on `http://localhost:5173`.
